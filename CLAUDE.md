# daily-print

A personal daily newspaper generated by an agent as a printable PDF. Product docs live in [docs/](docs/). Record new decisions in docs/DECISIONS.md, and keep docs/OPEN_QUESTIONS.md and docs/TODO.md current.

## Code style

- Short and sweet. Code should be easy for a person to read and understand.
- Don't add complexity that isn't needed now: no speculative abstractions, config options or layers.
- Don't repeat yourself. Reuse a helper instead of writing the same thing twice.
